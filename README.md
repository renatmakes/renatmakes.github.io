# Renat public OAuth information pages

This repository contains only the public OAuth disclosure pages for Renat's personal applications.

The published site is available at <https://renatmakes.github.io/>. Information for **Renat Tasks Bridge** is available at <https://renatmakes.github.io/google-tasks-mcp/>.

The MCP server source code is maintained in a separate private repository. Source code, tests, internal documentation, deployment material, archives, and lock files from that project are not published here.

Secrets, OAuth client credentials, access tokens, refresh tokens, and environment files must never be committed to this repository.

The site is plain static HTML and CSS. It has no analytics, cookies, forms, JavaScript, external fonts, CDN assets, or build dependencies.

No license file is included.
