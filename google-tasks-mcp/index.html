Renat Tasks Bridge

A personal bridge that lets its owner read selected information from their own Google Tasks account through an MCP integration used from ChatGPT.

Owner request → ChatGPT → MCP bridge → Google Tasks API

Current OAuth access

Read-only

The application currently requests only https://www.googleapis.com/auth/tasks.readonly. With this configuration it does not create, change, complete, or delete tasks.

Availability

Owner only

The integration is built for Renat's personal use and is not offered to other users. This website does not provide registration or account access.
