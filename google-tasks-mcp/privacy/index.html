Renat Tasks Bridge

Privacy Policy

Last updated: September 11, 2026

Renat Tasks Bridge is a private integration built for and used by its owner, Renat. This policy describes how the application handles Google Tasks data when the owner makes an explicit request through the MCP integration.

Google data the application can access

The current OAuth configuration requests only the read-only scope https://www.googleapis.com/auth/tasks.readonly. This scope may allow the application to read:

  • task list names and identifiers;
  • task titles and notes;
  • completion status and due dates;
  • task identifiers; and
  • task hierarchy data, including parent relationships when provided.

Purpose of processing

The data is used only to carry out the owner's explicit request and to show the selected information back to the owner through ChatGPT and the MCP integration. It is not used to build advertising profiles or for unrelated purposes.

Data transmission and sharing

  • The application accesses data through the Google Tasks API.
  • Selected results may be transmitted to OpenAI and ChatGPT when the owner invokes the corresponding MCP tool.
  • Processing performed by Google and OpenAI is governed by their own terms and privacy policies.
  • The application does not sell Google user data.
  • The application does not use Google user data for advertising.
  • The application does not disclose Google user data to other third parties.

Storage

  • OAuth credentials are stored only on a computer or server controlled by the owner, with access restricted by the owner.
  • Task content is not copied into a separate persistent database maintained by the application.
  • Technical logs are designed not to contain task titles, task notes, OAuth tokens, or HTTP authorization data.
  • This public website uses no cookies, analytics, forms, or client-side scripts.

Retention, revocation, and deletion

  • The local OAuth token remains stored until the owner deletes it or revokes the application's access.
  • The owner can revoke access from the connected-app settings in their Google Account.
  • The owner can delete the local OAuth files from the computer or server where the bridge runs.
  • The bridge does not retain task data as its own permanent record.
  • Retention by Google and OpenAI is governed by those services' respective policies.

Security and limitations

The application follows a least-privilege approach. Its current OAuth configuration is read-only, external service connections use HTTPS, and access to local OAuth files is restricted. No technical system can provide an absolute guarantee of security.

A future change to a write-capable scope would require separate owner consent and updated public disclosures before that configuration is used.

Google API Limited Use disclosure

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Privacy questions can be submitted through the public GitHub Issues page.
